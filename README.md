# Pentra — Penetration Testing Orchestration Platform

Pentra is an open-source, modular penetration testing workspace designed to centralize the entire security assessment lifecycle.

Built with a container-first architecture, Pentra integrates existing security tools into customizable workflows covering reconnaissance, enumeration, vulnerability assessment, manual validation, evidence collection, and professional reporting.

The platform aims to provide a unified CLI and web dashboard, persistent project history, reusable methodologies, automated tool execution, and cross-platform compatibility across Linux and Windows through Docker.

**One workspace. Multiple tools. Complete control.**
